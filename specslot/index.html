Overview

Pixel-space generative Transformers typically use one token per image patch, so capturing finer detail requires more tokens and makes global attention increasingly expensive. We observe that finer detail does not necessarily require more global communication: low-frequency structure benefits from global exchange, while high-frequency detail can be modeled locally. Based on this insight, we introduce SpecSlot, a pixel-space rectified-flow Transformer that decouples output detail from the length of the global attention sequence. SpecSlot expands each spatial anchor into multiple slots, each assigned a disjoint band of DCT coefficients; this separates anchor density from spectral subdivision. Only the lowest-frequency slot from each anchor participates in global attention, while all slots interact locally. This allows the model to increase spectral detail without enlarging the global sequence. A spatial head further adds a local correction to the spectral prediction, while the generative state, target, and loss remain in pixel space.

Tokenization
as allocation.

A patch size should not have to decide both output detail and global communication.

Finer detail need not require more global communication: low-frequency structure benefits from global exchange, while high-frequency detail can be modeled locally. SpecSlot turns this insight into an allocation of N = W × K image tokens: W sets spatial anchor density, and K sets spectral subdivision. At fixed W, more slots leave the global image sequence at W carriers. At fixed N, more anchors mean fewer slots per anchor, and the split changes compute cost.

Read the evidence,
then assign roles.

The input grid should determine where evidence comes from, not how many output roles the model can express. SpecSlot projects non-overlapping image cells into W spatial anchors. An input mixer lets neighboring anchors exchange evidence before each anchor expands into K slot states, with anchor and slot positions added. All K slots thus draw on the same local evidence but take different output roles, separating input density from spectral subdivision.
